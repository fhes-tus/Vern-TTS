# Vern 2.8.0

Android version name **2.8.0**, version code **47**.

- **On-Device Menu Translation**: Added an opt-in Google ML Kit on-device translation session for main Settings and App Language options when running on phone locales without dedicated translation packs. Features offline model management, cellular data download controls, and a privacy disclosure.
- **New Interface Language Packs**: Added complete preview resource translations for German (`de`), Korean (`ko`), Brazilian Portuguese (`pt`), and Russian (`ru`), joining existing Arabic (`ar`), Simplified Chinese (`zh-Hans`), Spanish (`es`), French (`fr`), and Hindi (`hi`) packs.
- **Reader & Original PDF Chrome Localization**: Fully localized Text, Listen, and Original document headers, summaries, controls, and PDF share/tool menus across all ten languages.
- **Pronunciation & Syntax Guide Walkthrough**: Added a numbered walkthrough and interactive examples for Pattern and Regex pronunciation rules, compact saved rule groups, and clarified rule management.
- **Cloud Narration & Usability**: Integrated Azure Speech and Google Cloud narration with authenticated voice catalogs, visible custom server endpoints, and improved voice download feedback.
- **Library & Navigation Polish**: Localized Library filter chips and reading pills, refined finished-book ordering, and preserved custom accent choices across themes.

Verification commands, results and tested platforms are recorded in [progress.md](progress.md). This source change does not publish a release.
