# Vern 2.8.1

Android version **2.8.1**, version code **48**.

- Layouts adapt to available window width and height, including rotation and short screens.
- Notes gains adaptive masonry columns; Study gains adaptive decks and supporting panels.
- The Add menu uses two columns and compact actions in short landscape windows.
- Improved large-text navigation, scrollable dialogs, keyboard clearance and native PDF controls.
- Separating fold features constrain supported content and dialogs to a usable pane.
- Reading, draft, selection and quiz state are preserved through the covered layout transitions.

Verification and its device limits are recorded in [progress.md](progress.md). Physical tablet and foldable acceptance remains pending. This file does not establish publication.
