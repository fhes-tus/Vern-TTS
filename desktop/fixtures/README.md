# Import fixtures

`alice-in-wonderland.txt` and `alice-in-wonderland.epub` are real public-domain book fixtures downloaded from [Project Gutenberg, ebook 11](https://www.gutenberg.org/ebooks/11). They retain their Gutenberg attribution and licence. They are test imports, not preloaded user-library entries.

The repository's `sherlock.pdf` is available for a manual PDF import without duplicating it here. Automated EPUB tests construct an explicitly synthetic two-chapter archive to verify spine ordering and script removal; they do not claim publisher-layout parity.
