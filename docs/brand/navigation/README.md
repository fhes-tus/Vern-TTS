Navigation uses Google's stock Material Symbols Rounded at 24 px and weight 400,
with outlined and filled variants. Colours come from the active app theme.

- Home: `home`
- Library: `newsstand` (upright books and a slanted book on a shelf)
- Notes: `note_stack`

Source: https://github.com/google/material-design-icons
License: Apache 2.0 (https://github.com/google/material-design-icons/blob/master/LICENSE)

SVG downloads follow the official Google Fonts pattern:
`https://fonts.gstatic.com/s/i/short-term/release/materialsymbolsrounded/{name}/default/24px.svg`
and `{name}/fill1/24px.svg` for filled variants.

Android vector resources retain the source paths and translate Google's negative-Y
viewport into Android's positive viewport. They are not custom approximations.
